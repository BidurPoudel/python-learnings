
if function/method name is more than one word use "_"

--> def add_numbers(number1: int, number2: int)

use "_" if variable more than one word

--> student_name = "Bidur Poudel", age_of_student = 20

for folder/file name same naming convention as method/variable
folder name -> user_authentications
file name -> login_authentications

class names should be in CamelCase
-> class ChoiceQuestion
